# Alert 104: New Admin Account Creation

**Incident classification:** True positive
**Does this alert require escalation?:** Yes

## Case Report

### Time of Activity

**09/11/2026 10:31:31.952**

### List of Affected Entities

| Entity                 | Details                        |
| ---------------------- | ------------------------------ |
| **User Context**       | `TRYHATME\Andrew.Miller`       |
| **Target Workstation** | `IT-TRYHATME`                  |
| **Created Account**    | `Michael.Myres`                |
| **Parent Process**     | `powershell.exe` (PID: `1405`) |
| **Child Process**      | `net.exe` (PID: `4700`)        |

### Reason for Classifying as True Positive

The compromised PowerShell process (`PID 1405`) identified in Alerts 102 and 103 spawned:

```text
C:\Windows\system32\net.exe
```

to execute:

```text
net.exe user Michael.Myres Halloween123 /add
```

This demonstrates an unauthorized threat actor using the compromised context of IT Manager Andrew Miller to establish persistence via local account creation.

### Reason for Escalating the Alert

Escalation is required because this activity represents active post-exploitation persistence mechanisms on workstation `IT-TRYHATME` as part of an ongoing multi-stage breach.

### Recommended Remediation Actions

1. **Immediately remove/disable** the newly created rogue account `Michael.Myres`.
2. **Maintain complete network isolation** of workstation `IT-TRYHATME`.
3. **Audit local Administrators group and Active Directory** for any additional backdoor accounts created during the compromise timeframe.
4. **Proceed with password resets** for `TRYHATME\Andrew.Miller`.
