# Alert 8821: Possible Brute Force Attack on Web Application

## Incident Classification

**True Positive**

## Escalation Required?

**No**

## Case Report

### Time of Activity

`09/08/2026 17:50:24.593`

### Affected Entities

| Entity                       | Details                                |
| :--------------------------- | :------------------------------------- |
| **Target Host**              | `192.168.100.38` — `prod` (Web Server) |
| **Target Domain**            | `thetrydaily.thm`                      |
| **Attacking IP**             | `24.48.63.112`                         |
| **Source User-Agent / Tool** | `Mozilla/4.0 (Hydra)`                  |

### Reason for Classifying as True Positive

An external IP address (`24.48.63.112`) attempted an **automated web application brute-force attack** against `/admin-login.php` on `thetrydaily.thm` (`192.168.100.38`).

The activity was logged via `modsec_audit` and utilized the credential-guessing tool **Hydra**, as identified by the `Mozilla/4.0 (Hydra)` User-Agent header and the presence of an HTTP Basic Authorization header (`Basic YWRtaW46Tn9xxZhE`).

The web server responded with **HTTP status code 401 (Unauthorized)**, confirming that the login attempt failed.

### Reason for Not Escalating the Alert

Escalation is not required because **all authentication attempts failed** (`HTTP 401`), resulting in no unauthorized access or compromise of the web application.

### Recommended Remediation Actions

* Block external source IP `24.48.63.112` at the **WAF/perimeter firewall** level.
* Implement **CAPTCHA or rate-limiting** (e.g., ModSecurity rules or Fail2ban) on `/admin-login.php` to prevent password spraying and brute-force attacks.
* Restrict access to administrative web interfaces such as `/admin-login.php` to **trusted IP ranges** or require VPN access.

## Analyst Verdict

**Classification:** True Positive
**Escalation:** No

The alert was confirmed as an **automated web application brute-force attempt** originating from `24.48.63.112`. The use of Hydra and an HTTP Basic Authorization header indicates credential-guessing activity against the administrative login endpoint. The server returned `401 Unauthorized`, indicating that the authentication attempt failed and no evidence of successful unauthorized access or compromise was identified.
