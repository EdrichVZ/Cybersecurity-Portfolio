# Alert 8817: Possible Multiple Unauthorized File Enumeration Attempts

## Incident Classification

**True Positive**

## Escalation Required?

**No**

## Case Report

### Time of Activity

`09/08/2026 17:40:58.593`

### Affected Entities

| Entity                       | Details                                |
| :--------------------------- | :------------------------------------- |
| **Target Host**              | `192.168.100.38` — `prod` (Web Server) |
| **Target Domain**            | `thetrydaily.thm`                      |
| **Attacking IP**             | `24.48.63.112`                         |
| **Source User-Agent / Tool** | `Mozilla/5.0 (Gobuster)`               |

### Reason for Classifying as True Positive

An external source IP (`24.48.63.112`) executed **multiple automated HTTP directory and file enumeration requests** against `thetrydaily.thm` (`192.168.100.38`) on port `80`.

The activity was logged in `modsec_audit.log` and clearly used the directory bruteforcing tool **Gobuster**, as identified by the `Mozilla/5.0 (Gobuster)` User-Agent header.

The server returned **HTTP 404 (Not Found)** responses for the probed paths, such as `GET /zt`, confirming that the scanned resources do not exist.

### Reason for Not Escalating the Alert

Escalation is not required per SOC guidelines. Although this represents **malicious reconnaissance activity (True Positive)**, the directory scanning returned `404` status codes, resulting in **no unauthorized access, system exposure, or secondary exploitation**.

### Recommended Remediation Actions

* Block or rate-limit the external source IP (`24.48.63.112`) at the **perimeter firewall/WAF**.
* Configure **ModSecurity rules** to automatically block requests containing known scanner User-Agents such as `Gobuster`.
* Ensure web application logging continues to monitor for **secondary probes** originating from this IP or subnet.

## Analyst Verdict

**Classification:** True Positive
**Escalation:** No

The alert was confirmed as **automated web directory and file enumeration activity** originating from the external IP `24.48.63.112`. The use of Gobuster and multiple HTTP requests indicates reconnaissance against the web server. The probed resource returned a `404 Not Found` response, and no evidence of unauthorized access, system exposure, or secondary exploitation was identified.
