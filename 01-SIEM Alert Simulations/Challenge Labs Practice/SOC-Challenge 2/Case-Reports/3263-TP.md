## Reason for Classifying as True Positive

The alert triggered due to multiple **failed VPN authentication attempts** originating from external source IP `2.120.15.78` and targeting user account `n.williams`.

This confirms **external brute-force/password-guessing activity**.

All attempts failed:

* `auth_status: failed`
* `session_status: denied`

This means that **no unauthorized VPN session was established**.

Based on the available evidence, the activity was classified as a **True Positive brute-force attempt**.

---

## Reason for Escalating the Alert

**N/A — No escalation required.**

Per SOC rules, failed external brute-force attempts that do not result in a successful login do not require escalation.

---

## Recommended Remediation Actions

* **Block external source IP** `2.120.15.78` on perimeter firewall `FW-CHARON-01`.
* Monitor user account `n.williams` for any subsequent **successful authentication events**.
* Continue monitoring VPN authentication logs for additional attempts from the same or other external sources.
