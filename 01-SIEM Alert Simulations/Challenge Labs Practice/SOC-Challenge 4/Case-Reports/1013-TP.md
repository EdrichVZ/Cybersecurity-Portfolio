# Alert 1013: Suspicious DNS Query

## Incident Classification

**True Positive**

## Escalation Required?

**Yes**

## Case Report

### Time of Activity

`09/08/2026 20:11:38.445`

### Affected Entities

| Entity | Details |
| :--- | :--- |
| **User** | `michael.ascot` — CEO |
| **Source Host** | `Lin-001` — `192.168.0.10` |
| **DNS Server** | `8.8.8.8` |
| **Queried Domain** | `wer484.tyhatme.xyz` |

### Reason for Classifying as True Positive

The alert was triggered after `Lin-001` (`192.168.0.10`) generated DNS queries for the suspicious domain `wer484.tyhatme.xyz`. The detection rule identifies **DNS queries associated with known Command-and-Control (C2) frameworks occurring at regular intervals**.

This activity is directly connected to the previous malicious activity identified on `Lin-001`. Earlier alerts showed the download of `installer.sh` from external IP `159.65.241.15`, executable permission changes, privileged activity as `root`, and a previous suspicious DNS query to `a1b2c3.tyhatme.xyz`.

The continued DNS activity to another suspicious domain associated with known C2 frameworks provides further evidence that `Lin-001` is **actively compromised and attempting to communicate with attacker-controlled infrastructure**.

### Reason for Escalating the Alert

Escalation is required because the suspicious DNS activity is part of the **ongoing attack chain involving Lin-001**.

The host has already demonstrated multiple indicators of compromise, including an anomalous VNC login, payload download, executable permission changes, privileged activity, and suspicious C2-related DNS queries.

The continued C2-related DNS activity indicates that the compromise remains active and requires immediate containment and investigation.

### Recommended Remediation Actions

- Immediately isolate `Lin-001` from the corporate network to prevent further C2 communication and lateral movement.
- Block `wer484.tyhatme.xyz` and previously identified malicious domains at DNS and perimeter security controls.
- Investigate DNS logs for additional queries originating from `192.168.0.10`.
- Analyze `installer.sh` and `/home/michael.ascot/.local/update` to determine their role in the C2 activity.
- Investigate running processes and network connections on `Lin-001` for additional indicators of compromise.
- Reset potentially compromised credentials associated with Michael Ascot.
- Correlate this alert with the previous alerts involving `Lin-001` as part of the same incident.
