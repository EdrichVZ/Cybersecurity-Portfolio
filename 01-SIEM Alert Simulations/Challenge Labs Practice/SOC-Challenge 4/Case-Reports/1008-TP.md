# Alert 1008: Chmod Suspicious Directory

## Incident Classification

**True Positive**

## Escalation Required?

**Yes**

## Case Report

### Time of Activity

`09/08/2026 19:59:15.445`

### Affected Entities

| Entity | Details |
| :--- | :--- |
| **User** | `michael.ascot` — CEO |
| **Host** | `Lin-001` — `192.168.0.10` |
| **Current Directory** | `/tmp` |
| **Target File** | `installer.sh` |

### Reason for Classifying as True Positive

The alert was triggered when the `chmod` utility was used on `Lin-001` to grant executable permissions (`+x`) to the shell script `installer.sh`:

`chmod +x installer.sh`

The asset inventory identifies `Lin-001` (`192.168.0.10`) as the workstation assigned to **Michael Ascot, CEO**. The SOC handover notes previously documented an **anomalous VNC login involving Michael on Lin-001**.

This activity directly follows Alert 1007, where `installer.sh` was downloaded from external IP `159.65.241.15` into the `/tmp` directory. Granting executable permissions to the newly downloaded script represents the next stage of the same suspected attack chain and indicates preparation of the payload for execution.

### Reason for Escalating the Alert

Escalation is required because the activity forms part of an ongoing **attack chain on Lin-001**. The host was previously associated with an anomalous VNC login, followed by the download of `installer.sh` in Alert 1007 and now the modification of the file permissions to make the script executable.

According to the SOC escalation guidelines, True Positive alerts connected to other alerts within the same attack chain require escalation. The activity indicates continued post-compromise actions and preparation for malicious payload execution.

### Recommended Remediation Actions

- Immediately isolate `Lin-001` from the corporate network to prevent further malicious activity or lateral movement.
- Prevent execution of `installer.sh` and preserve the file for forensic analysis.
- Analyze `installer.sh` to determine its functionality and identify additional indicators of compromise.
- Block communication with `159.65.241.15` at the perimeter firewall.
- Investigate the anomalous VNC login and correlate it with Alerts 1007 and 1008.
- Review authentication, process, and network logs associated with `michael.ascot` and `Lin-001`.
- Reset potentially compromised credentials associated with Michael Ascot.

## Analyst Verdict

**Classification:** True Positive  
**Escalation:** Yes

The alert was confirmed as **malicious post-compromise activity forming part of the ongoing attack chain on Lin-001**. Following the anomalous VNC login and the download of `installer.sh` from external IP `159.65.241.15` in Alert 1007, the script was given executable permissions using `chmod +x`. This indicates preparation of the downloaded payload for execution and requires immediate escalation, containment, and further investigation.
