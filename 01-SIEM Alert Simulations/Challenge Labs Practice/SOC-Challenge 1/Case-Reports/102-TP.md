# Alert 102: Suspicious Encoded Service Command Executed

**Incident classification:** True positive
**Does this alert require escalation?:** Yes

## Case Report

### Time of Activity

**09/11/2026 10:27:11.952**

### List of Affected Entities

| Entity          | Details                                                                                  |
| --------------- | ---------------------------------------------------------------------------------------- |
| **User**        | `TRYHATME\Andrew.Miller` (IT Manager)                                                    |
| **Workstation** | `IT-TRYHATME` (IP: `10.0.2.48`)                                                          |
| **Process**     | `C:\Windows\System32\services.exe` (Parent PID: `6712`) / `powershell.exe` (PID: `1405`) |

### Reason for Classifying as True Positive

The Windows Service Control Manager (`services.exe`) spawned a hidden PowerShell execution using obfuscated Base64 encoding:

```text
powershell.exe -WindowStyle Hidden -EncodedCommand JABJACAAP...
```

This behavior matches the SOC policy regarding suspicious obfuscated process execution and indicates malicious service creation or process injection.

### Reason for Escalating the Alert

Escalation is required per SOC guidelines because an attacker has executed obfuscated code on a corporate workstation (`IT-TRYHATME`), indicating host compromise and an ongoing attack chain.

### Recommended Remediation Actions

1. **Isolate host** `IT-TRYHATME` (`10.0.2.48`) from the network immediately.
2. **Decode and analyze** the Base64 PowerShell payload to identify secondary payloads.
3. **Reset credentials** for user `TRYHATME\Andrew.Miller`.
4. **Inspect system services** for persistence mechanisms.
