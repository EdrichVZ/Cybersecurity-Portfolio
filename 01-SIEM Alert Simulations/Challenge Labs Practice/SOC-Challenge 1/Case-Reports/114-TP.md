# Alert 114: System Shadow Copy Compromise

**Incident classification:** True positive
**Does this alert require escalation?:** Yes

## Case Report

### Time of Activity

**09/11/2026 11:03:48.952**

### List of Affected Entities

| Entity             | Details                                          |
| ------------------ | ------------------------------------------------ |
| **User Account**   | `TRYHATME\Michael.Myres` (Rogue account)         |
| **Target Host**    | `IT-TRYHATME`                                    |
| **Process**        | `C:\Windows\System32\vssadmin.exe` (PID: `7036`) |
| **Parent Process** | `C:\Windows\system32\cmd.exe` (PID: `9541`)      |

### Reason for Classifying as True Positive

The command shell spawned by the rogue administrator account `Michael.Myres` (Alert 110) executed Volume Shadow Copy Service administrative tool (`vssadmin.exe`):

```text id="1j0a9u"
vssadmin.exe delete shadows /all /quiet
```

This command forcefully deletes all system shadow copy backups silently to inhibit host recovery options, a standard precursor behavior to ransomware deployment or permanent destructive impact.

### Reason for Escalating the Alert

Escalation is required per SOC policy because an attacker is performing destructive defense evasion and inhibiting recovery mechanisms on a compromised internal workstation.

### Recommended Remediation Actions

1. **Maintain strict network isolation** on workstation `IT-TRYHATME`.
2. **Terminate all process trees** associated with PID `9541` (`cmd.exe`) and PID `7036` (`vssadmin.exe`).
3. **Initiate immediate host-level incident response routines** to check for ransomware staging, file encryption activity, or secondary persistence tools.
4. **Restore compromised system state** from offline/external uncorrupted backup repositories once the host is cleaned or re-imaged.
