### Reason for Classifying as True Positive

The process execution event shows command shell `cmd.exe` being launched under the newly created rogue administrator account `TRYHATME\Michael.Myres` via an interactive desktop shell (`explorer.exe`).

This directly correlates with the remote interactive desktop connection established in Alert 107, confirming the threat actor is actively executing commands on `IT-TRYHATME` using the rogue backdoor credentials.

### Reason for Escalating the Alert

Escalation is required because this activity confirms active hands-on-keyboard post-exploitation and command execution by an attacker using a backdoor administrator account on an internal workstation.

### Recommended Remediation Actions

1. **Immediately terminate all active processes** associated with user `Michael.Myres`.
2. **Delete/disable** the `Michael.Myres` account from the system and Active Directory.
3. **Enforce host network isolation** on `IT-TRYHATME` to stop ongoing attacker interaction.
4. **Audit system execution logs and command history** for all commands issued during this interactive session.
