# Alert 106: Suspicious Macro-Enabled Document Execution

**Incident classification:** False positive
**Does this alert require escalation?:** No

## Case Report

### Time of Activity

**09/11/2026 10:37:39.952**

### List of Affected Entities

| Entity          | Details                                                        |
| --------------- | -------------------------------------------------------------- |
| **User**        | `TRYHATME\Liam.Espinoza` (Finance Controller)                  |
| **Workstation** | `DESIGN-TRYHATME`                                              |
| **Process**     | `WINWORD.EXE` (PID: `1563`)                                    |
| **File Opened** | `C:\Users\Liam.Espinoza\Documents\Design_Portfolio_Costs.docm` |

### Reason for Classifying as False Positive

The alert triggered when Finance Controller Liam Espinoza opened a macro-enabled document (`Design_Portfolio_Costs.docm`) directly via Windows Explorer (`explorer.exe`).

Cross-referencing the SOC Handover Notes highlights a recent policy update regarding macro-enabled files:

> "The company has officially prohibited macro-enabled Office files (like *.docm or .xlsm) unless specifically approved by IT Security. The CISO announced this change via email. We should watch for any alerts or user complaints about blocked macros and remind employees of the new policy."

Because opening an internal work-related `.docm` document violates corporate policy rather than indicating a malicious exploit or initial access payload, it is classified as a false positive security alert.

### Reason for Escalating the Alert

**N/A (No escalation required).**

### Recommended Remediation Actions

1. **Contact user** (`Liam.Espinoza`) to notify them of the company policy prohibiting macro-enabled Office files.
2. **Request the user convert the file** to a standard `.docx` format or submit a request to IT Security if macro functionality is strictly required.

### List of Attack Indicators

**None (Policy compliance issue / Business document execution).**
