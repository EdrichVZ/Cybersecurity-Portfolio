# Alert 1006: Phishing Website Blocked

## Incident Classification

**True Positive**

## Escalation Required?

**No**

## Case Report

### Time of Activity

`09/08/2026 19:55:30.445`

### Affected Entities

| Entity               | Details                              |
| :------------------- | :----------------------------------- |
| **User**             | `armaan.terry`                       |
| **Host IP**          | `192.168.0.22` (Hostname: `Lin-013`) |
| **Device / Service** | Firewall                             |

### Reason for Classifying as True Positive

The alert was triggered by the firewall's "Block-Phishing-Sites" rule when internal host `192.168.0.22` attempted to navigate to the known phishing URL `http://slak.com` over HTTP (TCP port 80). The asset inventory correlates this IP to host `Lin-013`, assigned to user `armaan.terry`. This is classified as a True Positive because it involves genuine interaction with a malicious phishing threat. However, the firewall successfully intercepted and dropped the traffic (Action: blocked), preventing the user from accessing the malicious content.

### Reason for Escalating the Alert

N/A (No escalation required). According to SOC alert classification guidelines, escalation is not necessary when a threat is successfully blocked or quarantined before any user impact occurs.

### Recommended Remediation Actions

* No immediate technical remediation is required on host `Lin-013`, as the connection was successfully mitigated at the perimeter firewall.
* Consider following up with user `armaan.terry` to provide targeted security awareness training regarding clicking on unverified or suspicious external links.
