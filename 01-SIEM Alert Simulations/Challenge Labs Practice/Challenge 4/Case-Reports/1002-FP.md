# Alert 1002: Hacking Website Blocked

## Incident Classification

**False Positive**

## Escalation Required?

**No**

## Case Report

### Time of Activity

`09/08/2026 19:38:37.445`

### Affected Entities

| Entity                  | Details                              |
| :---------------------- | :----------------------------------- |
| **User**                | `yani.zubair` (IT Admin)             |
| **Host IP**             | `192.168.0.14` (Hostname: `Lin-005`) |
| **Destination Address** | `172.67.70.218` (Port: `443` / TCP)  |
| **Device / Service**    | Firewall                             |

### Reason for Classifying as False Positive

The alert was triggered by the firewall's "Block-Hacking-Sites" rule when host `192.168.0.14` attempted to access `https://abuseipdb.com`. According to the asset inventory, this IP belongs to `Lin-005`, used by IT Administrator Yani Zubair. The SOC handover notes explicitly state that Yani Zubair requested `https://abuseipdb.com` (along with `https://exploit-db.com` and `https://shodan.io`) to be added to the whitelist for legitimate use. This alert is a false positive resulting from a delayed or misconfigured implementation of that whitelist request.

### Reason for Escalating the Alert

N/A (No escalation required). The access attempt was blocked by the firewall (Action: blocked), and the destination is a legitimate security tool explicitly requested by the IT department.

### Recommended Remediation Actions

* Update the firewall configuration to successfully whitelist `https://abuseipdb.com`, `https://exploit-db.com`, and `https://shodan.io` for host `192.168.0.14` as requested by the IT administrator to prevent recurring false positive alerts.
* Close the alert.

## Analyst Verdict

**Classification:** False Positive
**Escalation:** No

The alert was triggered when `Lin-005` attempted to access `https://abuseipdb.com`, a legitimate security tool that IT Administrator Yani Zubair had explicitly requested to be whitelisted. The firewall successfully blocked the connection, and the activity is consistent with the authorized security-related activity documented in the SOC handover notes.
