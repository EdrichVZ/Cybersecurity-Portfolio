# Alert 1019: Phishing Website Blocked

## Incident Classification

**False Positive**

## Escalation Required?

**No**

## Case Report

### Time of Activity

`09/08/2026 20:30:17.445`

### Affected Entities

| Entity | Details |
| :--- | :--- |
| **Source IP** | `192.168.0.18` |
| **Destination IP** | `185.29.114.159` |
| **Destination URL** | `http://zo0m.us` |
| **Destination Port** | `80` |

### Reason for Classifying as False Positive

The alert was triggered when the internal host `192.168.0.18` attempted to access `http://zo0m.us`. The domain resembles the legitimate Zoom domain but replaces one of the letters with the number `0`, making it potentially consistent with **typosquatting**.

However, the firewall identified the destination through the `Block-Phishing-Sites` rule and successfully **blocked the connection**.

The available event does not show that the user successfully accessed the website, entered credentials, downloaded a file, or performed any other activity that would indicate compromise.

### Reason for Not Escalating the Alert

Escalation is not required because the firewall successfully prevented access to the suspicious destination.

There is no evidence in the available event of a successful connection or subsequent malicious activity from `192.168.0.18`. The preventative security control therefore operated as intended.

### Recommended Remediation Actions

- Close the alert as a **False Positive**.
- No immediate containment is required.
- Keep `zo0m.us` blocked by the firewall.
- Continue monitoring `192.168.0.18` for additional suspicious web activity.
- Investigate further if repeated phishing attempts or other indicators of compromise are observed.

## Analyst Verdict

**Classification:** False Positive  
**Escalation:** No

Alert 1019 was determined to be a **false positive because the suspicious connection was successfully blocked by the firewall**. The domain `zo0m.us` resembles a typosquatted version of the legitimate Zoom domain, but the event contains no evidence that the connection succeeded or that the endpoint was compromised. The firewall operated as intended and prevented access to the suspicious destination.
