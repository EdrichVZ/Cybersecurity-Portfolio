# Alert 107: Suspicious RDP Connection

**Incident classification:** True positive
**Does this alert require escalation?:** Yes

## Case Report

### Time of Activity

**09/11/2026 10:43:56.952**

### List of Affected Entities

| Entity                 | Details                                                             |
| ---------------------- | ------------------------------------------------------------------- |
| **User Context**       | `NT AUTHORITY\NETWORK SERVICE`                                      |
| **Target Host**        | `IT-TRYHATME.com` (IP: `10.0.2.48`, Destination Port: `3389` / RDP) |
| **Source External IP** | `85.203.21.23 (Malicious)` (Source Port: `85412`)                               |
| **Process**            | `C:\Windows\System32\svchost.exe` (PID: `2698`)                     |

### Reason for Classifying as True Positive

An inbound Remote Desktop Protocol (RDP) connection on port 3389 was established directly from the malicious external IP address `85.203.21.23` to workstation `IT-TRYHATME` (`10.0.2.48`).

This external IP matches the C2 IP address identified in Alert 103, confirming external interactive remote access by the threat actor to the compromised host.

### Reason for Escalating the Alert

Escalation is required per SOC guidelines because a threat actor has established direct unauthorized remote desktop access to an internal corporate workstation from an external IP as part of an active attack chain.

### Recommended Remediation Actions

1. **Enforce perimeter firewall rules** blocking external inbound RDP traffic (TCP 3389).
2. **Block malicious external IP** `85.203.21.23` at the firewall level.
3. **Maintain complete isolation** of workstation `IT-TRYHATME` (`10.0.2.48`) to terminate active remote sessions.
4. **Audit active network connections and system logon events** (Event ID 4624 Type 10) on the target system.
