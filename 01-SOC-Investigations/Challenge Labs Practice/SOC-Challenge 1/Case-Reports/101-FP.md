# Alert 101: Suspicious Internal Connection to Backup Server

**Incident classification:** False positive
**Does this alert require escalation?:** No

## Case Report

### Time of Activity

**09/11/2026 10:24:01.952**

### List of Affected Entities

| Entity          | Details                               |
| --------------- | ------------------------------------- |
| **User**        | `TRYHATME\Yani.Zubair` (IT Engineer)  |
| **Workstation** | `WEB2-TRYHATME` (IP: `10.0.2.19`)     |
| **Server**      | `BACKUP2-TRYHATME` (IP: `10.0.0.100`) |

### Reason for Classifying as False Positive

The alert triggered due to a process creation event executing standard native backup tools:

```text
C:\Windows\System32\wbadmin.exe start backup -backupTarget:\\10.0.0.100\backups -include:C:\Data -quiet
```

Crossreferencing company documentation confirms Yani Zubair is an authorized IT Engineer operating workstation `WEB2-TRYHATME`, and `10.0.0.100` is internal Backup Server 2.

The activity aligns directly with legitimate IT backup operations.

### Reason for Escalating the Alert

**N/A (No escalation required).**

### Recommended Remediation Actions

Tune detection rule criteria to exclude legitimate administrative backup tasks originating from authorized IT accounts to known backup endpoints.

### List of Attack Indicators

**None (Legitimate administrative activity).**
