# Alert 105: Cleartext Credentials File Access

**Incident classification:** False positive
**Does this alert require escalation?:** No

## Case Report

### Time of Activity

**09/11/2026 10:35:06.952**

### List of Affected Entities

| Entity            | Details                                         |
| ----------------- | ----------------------------------------------- |
| **User**          | `TRYHATME\Amanda.Lee` (Finance Manager)         |
| **Workstation**   | `FINANCE2-TRYHATME`                             |
| **Process**       | `C:\Windows\System32\notepad.exe` (PID: `4456`) |
| **File Accessed** | `C:\Users\Amanda.Lee\Documents\savedcreds.txt`  |

### Reason for Classifying as False Positive

The alert triggered when Finance Manager Amanda Lee opened `savedcreds.txt` via `notepad.exe` launched directly from Windows Explorer (`explorer.exe`).

Cross-referencing the SOC Handover Notes explicitly highlights this exact policy violation:

> "A few employees were found saving passwords in .txt files on their desktops. We should watch for more instances and encourage secure storage solutions (like password vaults)."

Because this is a user policy violation (unsafe password hygiene) rather than an external threat actor or malicious credential harvesting tool, it is classified as a false positive security alert.

### Reason for Escalating the Alert

**N/A (No escalation required).**

### Recommended Remediation Actions

1. **Reach out to the user** (`Amanda.Lee`) to mandate the removal of cleartext credentials stored on disk.
2. **Onboard the user** to the company-approved password vault solution per security policy guidance.

### List of Attack Indicators

**None (Policy compliance issue / Non-malicious user activity).**
