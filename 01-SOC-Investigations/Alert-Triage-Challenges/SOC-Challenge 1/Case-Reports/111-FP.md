# Alert 111: Suspicious Internal Connection to Backup Server

**Incident classification:** False positive
**Does this alert require escalation?:** No

## Case Report

### Time of Activity

**09/11/2026 10:55:30.952**

### List of Affected Entities

| Entity          | Details                                          |
| --------------- | ------------------------------------------------ |
| **User**        | `TRYHATME\Diego.Simeone` (IT Engineer)           |
| **Workstation** | `WEB-TRYHATME`                                   |
| **Process**     | `C:\Windows\System32\robocopy.exe` (PID: `8523`) |
| **Destination** | `10.0.99.99` (`\\10.0.99.99\BackupShare`)        |

### Reason for Classifying as False Positive

The alert triggered due to process execution using Windows Robust File Copy:

```text
C:\Windows\System32\robocopy.exe C:\Data \\10.0.99.99\BackupShare /MIR
```

Cross-referencing company documentation confirms Diego Simeone is an authorized IT Engineer operating workstation `WEB-TRYHATME`, and `10.0.99.99` is an internal backup server share.

The activity represents standard routine administrative backup operations carried out by authorized IT personnel.

### Reason for Escalating the Alert

**N/A (No escalation required).**

### Recommended Remediation Actions

Tune detection signatures to allow `robocopy.exe` executions originating from authorized IT accounts connecting to internal backup shares (`10.0.99.99`).

### List of Attack Indicators

**None (Legitimate IT maintenance activity).**
