# Alert 8829: Suspicious Parameter in Web Request

## Incident Classification

**True Positive**

## Escalation Required?

**Yes**

## Case Report

### Time of Activity

`09/08/2026 18:24:44.593`

### Affected Entities

| Entity            | Details                                                                  |
| :---------------- | :----------------------------------------------------------------------- |
| **Target Host**   | `192.168.100.38` — `prod` (Web Server)                                   |
| **Target Domain** | `thetrydaily.thm`                                                        |
| **Attacking IP**  | `24.48.63.112`                                                           |
| **User-Agent**    | `Mozilla/5.0 (X11; Linux x86_64; rv:102.0) Gecko/20100101 Firefox/102.0` |

### Reason for Classifying as True Positive

Following the successful brute-force attack on `/admin-login.php` (Alert 8825), the attacker (`24.48.63.112`) authenticated using Basic Authorization (`Basic YWRtaW46ZGZya3pya3pOTg3g3`) and performed a file upload attack via a `POST` request to `/admin/upload.php?action=upload`.

The uploaded file was named `easy-simple-php-webshell.php` (342 bytes). The server responded with HTTP status **200 (OK)**, confirming that a PHP webshell was successfully uploaded to the web server.

### Reason for Escalating the Alert

Immediate escalation is critical due to active post-exploitation activity and remote code execution capability resulting from a successfully placed webshell on production server `192.168.100.38`.

### Recommended Remediation Actions

* Immediately isolate host `192.168.100.38` from the network to prevent lateral movement or C2 activity.
* Block external IP address `24.48.63.112` at the perimeter firewall/WAF.
* Locate and delete the uploaded file `easy-simple-php-webshell.php` and perform a full file integrity and web root audit.
* Invalidate all administrative sessions and reset credentials for the admin portal.
* Restrict file upload extensions on `/admin/upload.php` to prevent execution of server-side scripts (e.g., disable PHP execution in upload directories).

## Analyst Verdict

**Classification:** True Positive
**Escalation:** Yes

The alert confirms **successful post-exploitation activity** following the earlier compromise of the web application's administrative portal. The attacker successfully uploaded a PHP webshell to the production web server, creating a potential **remote code execution** capability. Immediate incident response and containment are required.
