# Alert 1002: Hacking Website Blocked

## Incident Classification

**False Positive**

## Escalation Required?

**No**

## Case Report

### Time of Activity

`09/08/2026 19:38:37.445`

### Affected Entities

| Entity | Details |
| :--- | :--- |
| **User** | `yani.zubair` — IT Administrator |
| **Source Host** | `Lin-005` — `192.168.0.14` |
| **Destination IP** | `172.67.70.218` |
| **Destination URL** | `https://abuseipdb.com` |
| **Device / Service** | Firewall |

### Reason for Classifying as False Positive

The alert was triggered by the firewall's `Block-Hacking-Sites` rule when internal host `192.168.0.14` attempted to access `https://abuseipdb.com`.

The asset inventory identifies `192.168.0.14` as `Lin-005`, the workstation assigned to IT Administrator **Yani Zubair**. The SOC handover notes specifically state that Yani Zubair requested `https://abuseipdb.com`, along with `https://exploit-db.com` and `https://shodan.io`, to be added to the whitelist because these websites are required for his legitimate IT security activities.

The alert therefore represents **authorized access to a legitimate security resource that was incorrectly blocked by the firewall**, making the activity a False Positive.

### Reason for Not Escalating the Alert

Escalation is not required because the destination website was specifically documented in the SOC handover notes as an **approved security resource used by the IT administrator**. The firewall also blocked the connection, and there is no evidence of malicious activity or unauthorized access.

### Recommended Remediation Actions

- Close the alert as a **False Positive**.
- Add `https://abuseipdb.com` to the approved firewall whitelist as requested in the SOC handover notes.
- Verify that `https://exploit-db.com` and `https://shodan.io` are also correctly whitelisted to prevent similar false positive alerts.
- Review the `Block-Hacking-Sites` firewall rule to ensure approved security resources are excluded from blocking.

## Analyst Verdict

**Classification:** False Positive  
**Escalation:** No

The alert was determined to be a **false positive caused by legitimate access to an approved security resource being blocked by the firewall**.
