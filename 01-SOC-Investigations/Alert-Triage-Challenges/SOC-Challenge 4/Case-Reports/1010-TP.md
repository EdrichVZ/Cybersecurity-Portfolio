# Alert 1010: Suspicious DNS Query

## Incident Classification

**True Positive**

## Escalation Required?

**Yes**

## Case Report

### Time of Activity

`09/08/2026 19:59:41.445`

### Affected Entities

| Entity | Details |
| :--- | :--- |
| **User** | `michael.ascot` — CEO |
| **Source Host** | `Lin-001` — `192.168.0.10` |
| **DNS Server** | `8.8.8.8` |
| **Queried Domain** | `a1b2c3.tyhatme.xyz` |

### Reason for Classifying as True Positive

The alert was triggered when `Lin-001` (`192.168.0.10`) generated a DNS query for the suspicious domain `a1b2c3.tyhatme.xyz`. The detection rule specifically identifies **DNS queries associated with known Command-and-Control (C2) frameworks**.

This activity directly follows the suspicious events identified in Alerts 1007, 1008, and 1009. `Lin-001` first downloaded `installer.sh` from external IP `159.65.241.15`, the script was then given executable permissions, and subsequent activity running as `root` granted executable permissions to `/home/michael.ascot/.local/update`.

The DNS query occurring immediately after these events strongly indicates that the compromised host is attempting to **communicate with attacker-controlled Command-and-Control infrastructure**.

### Reason for Escalating the Alert

Escalation is required because this activity is part of the ongoing **attack chain involving Lin-001** and provides additional evidence that the workstation has been compromised.

The progression from an anomalous VNC login to payload download, executable permission changes, privileged activity, and now a suspicious DNS query associated with C2 infrastructure indicates active post-compromise behavior.

According to the SOC escalation guidelines, True Positive alerts connected to other alerts within the same attack chain require escalation.

### Recommended Remediation Actions

- Immediately isolate `Lin-001` from the corporate network to prevent further C2 communication and lateral movement.
- Block the domain `a1b2c3.tyhatme.xyz` at the DNS resolver and perimeter security controls.
- Investigate DNS and network logs for additional communication involving `a1b2c3.tyhatme.xyz`.
- Analyze `installer.sh` and `/home/michael.ascot/.local/update` to determine whether either payload initiated the DNS query.
- Investigate the anomalous VNC login and correlate it with Alerts 1007–1010.
- Review `Lin-001` for additional persistence mechanisms, malicious processes, and network connections.
- Reset potentially compromised credentials associated with Michael Ascot and review privileged account activity.

## Analyst Verdict

**Classification:** True Positive  
**Escalation:** Yes

The alert was confirmed as **suspicious DNS activity associated with the ongoing compromise of Lin-001**. Following the anomalous VNC login, payload download, permission changes, and privileged activity identified in previous alerts, the host queried `a1b2c3.tyhatme.xyz`, a domain detected as being associated with C2 frameworks. The activity provides further evidence of active post-compromise behavior and requires immediate containment and investigation.
