# Alert 1009: Chmod Suspicious Directory

## Incident Classification

**True Positive**

## Escalation Required?

**Yes**

## Case Report

### Time of Activity

`09/08/2026 19:59:39.445`

### Affected Entities

| Entity | Details |
| :--- | :--- |
| **User** | `root` |
| **Host** | `Lin-001` — `192.168.0.10` |
| **Current Directory** | `/tmp` |
| **Target File** | `/home/michael.ascot/.local/update` |

### Reason for Classifying as True Positive

The alert was triggered when the `chmod` utility was used with **root privileges** on `Lin-001` to grant executable permissions (`+x`) to the file `/home/michael.ascot/.local/update`:

`chmod +x /home/michael.ascot/.local/update`

This activity occurs immediately after Alerts 1007 and 1008, where `installer.sh` was downloaded from external IP `159.65.241.15` into `/tmp` and subsequently given executable permissions.

The SOC handover notes also documented an **anomalous VNC login involving Michael Ascot on Lin-001**. The appearance of activity running as `root`, combined with the creation or preparation of an executable named `update` inside the hidden `.local` directory of Michael Ascot's home directory, strongly indicates continued **post-compromise activity** on the host.

### Reason for Escalating the Alert

Escalation is required because this activity is directly connected to the ongoing **attack chain on Lin-001**.

The activity has progressed from an anomalous VNC login to downloading an external shell script, making that script executable, and now using `root` privileges to make another file executable within Michael Ascot's `.local` directory.

This indicates that the compromise has progressed beyond the initial payload download and now involves **privileged activity on the system**. According to the SOC escalation guidelines, True Positive alerts connected to a larger attack chain require escalation.

### Recommended Remediation Actions

- Immediately isolate `Lin-001` from the corporate network.
- Investigate how `root` privileges were obtained on the host.
- Preserve and analyze `/home/michael.ascot/.local/update` to determine its functionality and origin.
- Analyze `installer.sh` from Alert 1007 to determine whether it created or deployed the `update` file.
- Block communication with external IP `159.65.241.15`.
- Review authentication, VNC, process, and privilege-related logs on `Lin-001`.
- Reset potentially compromised credentials associated with Michael Ascot and review privileged accounts for unauthorized access.

## Analyst Verdict

**Classification:** True Positive  
**Escalation:** Yes

The alert was confirmed as **continued post-compromise activity on Lin-001**. Following the anomalous VNC login and malicious activity identified in Alerts 1007 and 1008, a process running as `root` granted executable permissions to `/home/michael.ascot/.local/update`. The progression to privileged activity and preparation of an additional executable indicates that the attack chain is continuing and requires immediate containment and investigation.
